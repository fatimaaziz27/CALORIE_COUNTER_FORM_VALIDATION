# CALORIE COUNTER FORM VALIDATION

A simple calorie counter project built with **HTML, CSS, and JavaScript** to practice form validation, user input handling, DOM manipulation, and calculations.

## About

This project is based on the **Calorie Counter** practice project from freeCodeCamp.

It allows users to enter a daily calorie budget and add calorie values for different meal categories and exercise. JavaScript processes the entered information and calculates the calorie result.

The project also focuses on validating form inputs and handling invalid user entries.

## How It Works

### 1. Enter Calorie Budget

The user enters their daily calorie budget.

### 2. Add Calories

The user can enter calorie values for:

* Breakfast
* Lunch
* Dinner
* Snacks
* Exercise

### 3. Calculate Calories

JavaScript processes the entered values and calculates the total calorie result.

### 4. Validate Input

The form checks user input and displays an error when invalid data is entered.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the required information.
5. Use the calorie counter to calculate the result.

No additional installation is required.
