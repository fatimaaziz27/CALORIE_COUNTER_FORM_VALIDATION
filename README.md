# CALORIE COUNTER FORM VALIDATION

A simple calorie counter project built with **HTML, CSS, and JavaScript** to practice form validation, user input handling, DOM manipulation, and calculations.

## About

This project is based on the **Calorie Counter** practice project from freeCodeCamp.

It allows users to enter a daily calorie budget and add calorie values for different meal categories and exercise. JavaScript processes the entered information and calculates the calorie result.

The project also focuses on validating form inputs and handling invalid user entries.

## JavaScript Concepts Practiced

* DOM Manipulation
* Event Handling
* Arrays
* Objects
* Conditional Statements
* Form Handling
* Form Validation
* Input Validation
* Number Conversion
* String Methods
* Regular Expressions
* Error Handling

## Purpose

The main purpose of this project is to strengthen **JavaScript fundamentals** through a practical form-based application.
