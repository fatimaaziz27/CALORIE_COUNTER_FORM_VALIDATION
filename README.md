# CALORIE COUNTER FORM VALIDATION

A JavaScript project built to practice **form validation, user input handling, calorie calculations, and DOM manipulation** by creating a calorie counter.

## About

This project is based on the **Calorie Counter** project from freeCodeCamp's JavaScript curriculum.

The project focuses on building and validating a form where users can enter calorie information and calculate their remaining calories. It provides practice with JavaScript form handling and input validation.

## How It Works

The user enters a daily calorie budget and adds calorie values for different categories such as:

* Breakfast
* Lunch
* Dinner
* Snacks
* Exercise

The JavaScript processes the entered values and calculates the remaining calories.

The form also validates user input and displays appropriate errors when invalid values are entered.

## Form Validation

The project demonstrates how JavaScript can validate form inputs before processing the data.

Validation helps prevent incorrect or invalid values from being used in the calorie calculation.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the required calorie information.
5. Click the calculate button to see the result.

No additional installation is required.
